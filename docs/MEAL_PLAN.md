# 식단표 자동 생성

FoodVOC의 **식단표** 탭은 평일 단체급식 식단표(1·2·4주)를 자동으로 만듭니다.
계산은 모두 브라우저 안에서 이루어지며, 외부 사이트나 서버에 접속하지 않습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `src/data/mealPlanItems.ts` | 메뉴 DB (밥, 국, 탕·찌개, 주찬, 부찬, 무침·나물, 김치, 일품) |
| `src/data/mealPlanNutrition.ts` | 메뉴별 100g당 열량·단백질·나트륨 (식약처 음식 DB에서 옮긴 값, 스크립트가 생성) |
| `scripts/buildMealPlanNutrition.py` | 위 파일을 만드는 스크립트와 앱 메뉴명 ↔ DB 음식명 짝짓기 표 |
| `src/utils/mealPlanGenerator.ts` | 생성 엔진, 영양 합계·목표 판정, 칸 바꾸기, 요약·경고, 엑셀용 TSV 변환 |
| `src/components/MealPlanner.tsx`, `src/mealPlan.css` | 입력 폼, 주차별 표(데스크톱), 요일별 카드(모바일), 하루 합계 막대 |

## 데이터 원칙

- **외부 자동 수집을 하지 않습니다.** 앱 코드에는 외부 사이트를 호출하거나 주기적으로 데이터를 가져오는 기능이 없고, 앞으로도 넣지 않습니다.
- `preferred: true` 메뉴는 2026년 9~11월 대형 단체급식 현장의 만족도 평가(별점 4.5점 이상, 평가 10명 이상)를 한 차례 참고해 **일반 메뉴명으로만** 정리한 것입니다.
  출처 사이트명, 별점 수치, 평가 인원, 날짜, 상호·행사명은 저장하지 않습니다.
- `preferred: false` 메뉴(화면의 '보충' 표시)는 조합을 채우기 위해 추가한 일반 메뉴입니다.
- 식재료 원가는 검증된 데이터가 없어 계산하지 않습니다.
- 앞으로 선호 표시는 직접 확보한 자료(자체 만족도 조사, FoodVOC VOC 기록, 사용 허락을 받은 자료)로 보강합니다.

## 영양 계산

- **출처:** 식품의약품안전처 식품영양성분 데이터베이스(Korean Food Composition Database system, K-FCDB) 음식 DB 2026-08-28판.
  사용자 승인을 받아 엑셀 파일을 내려받아 필요한 메뉴의 수치만 옮겼습니다(2026-11-16 나트륨 추가 때 같은 판을 승인받아 다시 받음). 원본 파일은 저장소에 넣지 않습니다.
- **짝짓기:** 앱 메뉴 219개 중 211개를 DB 음식과 사람이 직접 짝지었습니다(`scripts/buildMealPlanNutrition.py`의 `MAPPING`).
  메뉴명이 DB와 다르면 같은 종류·주재료·조리법의 가장 가까운 음식 수치를 씁니다(예: 돼지불백 → 돼지불고기_간장, 유린기 → 깐풍기).
  두 음식의 합으로 볼 수 있으면 둘을 더합니다(예: 나물떡갈비솥밥 → 비빔밥 + 떡갈비). 화면의 '영양 계산 근거'에서 메뉴별 DB 음식명을 볼 수 있습니다.
  가까운 음식을 찾지 못한 8개(맑은우동국, 백짬뽕탕, 닭보쌈, 돼지고기단호박조림, 모둠쌈과 쌈장, 양배추쌈과 쌈장, 연근흑임자무침, 스팸마요덮밥)는
  "영양 자료 없음"으로 표시하고 합계에서 뺍니다. 수치를 추정해 넣지 않습니다.
- **나트륨:** DB의 100g당 나트륨에 1인 분량을 곱합니다. 국·탕·면은 국물을 모두 먹었을 때 기준이라 실제 섭취량보다 높게 나올 수 있습니다.
  - 값의 근거: 같은 음식의 **분석 함량** 값을 우선합니다. 재료량 기반 값은 카레 루·육수 베이스처럼 양념의 나트륨이 빠져 낮게 나올 수 있어,
    분석 값이 없고 100g당 50mg(볶음·조림·구이는 150mg) 미만이면 '나트륨 자료 없음'으로 둡니다(밥류 제외). 현재 3개 메뉴(단호박찜·알감자버터구이·오이무침)가 해당하며, 생성할 때 뒤로 미뤄 하루 1개까지만 둡니다.
  - 설렁탕·곰탕·도가니탕·사골우거지탕은 손님이 소금으로 간을 하므로 DB 값에 소금이 빠져 있다고 화면에 '소금 별도'로 표시합니다.
  - 덮밥처럼 두 음식을 합친 메뉴는 쌀밥을 한 공기(210g)로 보고 합칩니다.
  - 1식 영양 목표에 **나트륨 상한**(기본 사무직 1,500mg·생산직 1,700mg, 하루 기준 2,300mg의 약 2/3)을 두고, 넘는 날은 경고에 적습니다.
    생성 중에는 상한을 넘는 만큼 점수를 깎고, 피할 요소로 '염도'를 고르면 더 크게 깎습니다.
  - 하루 기준 2,300mg은 한국인 영양소 섭취기준의 성인 만성질환위험감소섭취량이며, 한 끼가 이를 넘으면 경고에 함께 적습니다.
- **자료 구분 우선순위:** 산업체급식 → 중고등학교급식 → 초등학교급식 → 외식 → 가정식. 프랜차이즈 업체 제공 수치는 쓰지 않습니다.
- **계산식:** 1인 열량·단백질 = DB의 100g당 수치 × 화면에서 정한 1인 분량(g) ÷ 100.
  DB에 적힌 "식품중량"은 음식마다 기준이 달라(쌀밥 450g, 김치 100g 등) 1인 분량으로 쓰지 않습니다.
- **1인 분량 기본값(g):** 사무직 — 밥 250, 국 250, 탕·찌개 350, 주찬 130, 부찬 70, 무침·나물 60, 김치 40, 일품 550.
  생산직 — 밥 330, 탕·찌개 400, 주찬 170, 부찬 80, 일품 650(나머지 동일). 흔히 쓰는 배식량을 기준으로 잡은 초안이며 화면에서 바꿉니다.
- **1식 목표 기본값:** 사무직 700~800kcal·단백질 20g 이상, 생산직 850~950kcal·25g 이상.
  한국인 영양소 섭취기준(성인)의 하루 권장량을 세 끼로 나눈 값을 기준으로 잡은 초안이며 화면에서 바꿉니다.
- **판정:** 하루 합계가 목표 범위면 "목표 범위", 벗어나면 "부족"·"초과"로 표시하고 경고에 적습니다.
  영양 자료가 빠진 메뉴가 있는 날은 합계가 실제보다 작으므로 "일부 자료 없음"으로 표시하고, 이미 상한을 넘은 경우만 "초과"로 판정합니다.
- **한계:** 표준 레시피 기준 참고값입니다. 실제 레시피·배식량과 다를 수 있으므로 영양 표시에 쓰기 전에 영양사가 확인해야 합니다.

### 영양 자료를 다시 만들 때

1. K-FIND 사이트에서 음식 DB 엑셀을 내려받아 탭 구분 텍스트로 바꿉니다(첫 줄은 열 이름).
2. `python scripts/buildMealPlanNutrition.py <파일.tsv> <DB 버전>`을 실행합니다.
3. 메뉴를 추가했다면 `MAPPING`에 DB 음식명을 짝지어 줍니다. 짝지을 음식이 없으면 비워 둡니다.

## 생성 규칙

하루 식단은 6칸입니다: 밥(또는 일품) · 국(또는 탕·찌개) · 주찬 · 부찬 · 무침·나물 · 김치

- 요일 유형: **정식**, **탕·찌개**(국 칸에 탕·찌개), **일품**(밥 칸에 덮밥·비빔밥·면, 주찬 없음, 국물 있는 면은 국 생략)
- 일품은 수·금, 탕·찌개는 화·목·월 순서로 배치합니다.
- 다음과 같은 경우 점수를 깎아 피합니다.
  - 기간 안에 같은 중심 메뉴(주찬·탕찌개·일품) 반복, 가까운 날짜에 같은 국·반찬
  - 이틀 연속 같은 단백질, 같은 날 같은 단백질
  - 같은 날 주찬·부찬의 조리법 중복, 튀김 2개 이상, 주재료 중복
  - 같은 계열 메뉴(예: 짜장면·간짜장, 설렁탕·곰탕)를 3일 안에 배치
  - 매운 메뉴가 하루에 몰리는 경우
  - 사용자가 고른 VOC 요소(염도, 뼈·가시, 튀김 눅눅함, 매운맛)
  - 하루 열량이 목표 범위를 벗어나거나 단백질이 목표에 못 미치는 조합
  - 영양 자료가 없는 메뉴(합계를 확인할 수 없어 뒤로 미룸)
- `cold` 표시 메뉴(막국수, 냉소바)는 여름에만 사용합니다.
- 같은 조건이면 같은 결과가 나오고, "다른 조합으로 다시 생성"을 누르면 시드가 바뀝니다.

## 메뉴 추가 방법

`src/data/mealPlanItems.ts`에서 해당 칸의 배열에 한 줄을 추가합니다.

```ts
// [메뉴명, 단백질, 조리법, 주재료[], 주의표시[], 선호여부(기본 true)]
['고등어무조림', '생선', '조림', ['고등어', '무'], ['bones', 'salty'], false],
```

- 주재료는 같은 날 중복 판정에 쓰이므로 대표 재료 1~3개만 적습니다.
- 근거 자료가 없는 메뉴는 선호여부를 `false`로 둡니다.
